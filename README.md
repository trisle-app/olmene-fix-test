# olmene-fix-test

A small, fictional static site ("Brewline") used to test Olmene's fix agent
end to end. It is served by GitHub Pages and has deliberate issues for the
agent to fix: a short title, no meta description, no canonical URL, no
JSON-LD, no sitemap.xml or robots.txt, an image without alt text, and no
pricing link on the homepage.

Created on 2026-10-07 for a pre-launch test. Safe to delete afterwards.
